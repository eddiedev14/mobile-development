## How to install the PWA in a phone

### Android

1. Abre Google Chrome.
2. Ingresa a https://contact-pwa.netlify.app.
3. Cuando la aplicación haya cargado, abre el menú del navegador tocando los tres puntos (⋮) en la esquina superior derecha.
4. Selecciona "Instalar aplicación" o "Añadir a pantalla de inicio".
5. Confirma la instalación.
6. La aplicación se añadirá a la pantalla de inicio y podrás abrirla como una aplicación móvil normal.

### iPhone / iOS

1. Abre Safari en tu iPhone.
2. Ingresa a https://contact-pwa.netlify.app.
3. Toca el botón Compartir en la parte inferior de la pantalla.
4. Desplázate hacia abajo y selecciona "Añadir a pantalla de inicio".
5. Confirma tocando "Añadir".
6. La aplicación aparecerá en tu pantalla de inicio y podrás abrirla como una aplicación normal.

> [!NOTE]
> En iOS, la PWA debe instalarse utilizando Safari. Otros navegadores pueden no ofrecer las mismas opciones de instalación.

Una vez instalada, la PWA podrá ejecutarse directamente desde la pantalla de inicio del dispositivo, sin necesidad de abrir manualmente el navegador e introducir la dirección del sitio web. }

> [!TIP]
> Se recomienda probar la funcionalidad de caché, deshabilitando la conexión a internet e ingresando offline para verificar que la aplicación carga.
